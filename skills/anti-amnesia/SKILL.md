# Anti-Amnesia Skill

Use this skill before and after every non-trivial task.

## Before
1. Read current state and latest relevant ledger entries.
2. Identify active objective, repository, worktree, branch, pending confirmation, decisions, and blockers.
3. Validate that the requested task has not already been completed.
4. Build a minimal evidence-linked context bundle.
5. Record the planned task entry.

## During
- Record decision points, not private chain-of-thought.
- Preserve command outputs and test evidence.
- Mark assumptions and unresolved contradictions.
- Checkpoint durable tasks.

## After
- Append a factual ledger entry.
- Update current state atomically.
- Update decision and risk indexes.
- Record exact next safe action.
- Never rewrite history.
