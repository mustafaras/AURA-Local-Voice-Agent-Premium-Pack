## Authority for the expanded scope

`EV-SP-030-20260830-A11Y-COVERAGE-02` deliberately left three surfaces English —
the permission readout, `MemoryRowView` metadata, and `AuraSettingsView` — on the
reasoning that each needed new Turkish no native speaker had reviewed, and that
adding more unreviewed translation is not a way out of a blocker that *is*
unreviewed translation. The owner was asked directly and chose **"Fix it and the
rest"**, accepting the larger review burden. This record covers that expansion.

**That choice authorizes the work, not the sign-off.** It is recorded as a scope
decision, not as review. `accessibility_localization` stays **REFUSED**.

## The repo-wide guard the risk register asked for

`RISK_REGISTER.md` asked for "a test that fails when an accessibility string has no
Turkish counterpart" and recorded that one "would currently fail". It no longer
does. `AuraCopyTableGuardTests` (five tests) asserts:

- the table is non-empty (so the guard cannot pass vacuously if `allKeys` breaks);
- every key resolves in both languages and never falls through to its own name;
- every key is genuinely translated, **except two allowlisted by design**;
- the allowlist is minimal and still accurate — an entry that is no longer
  identical fails, so it cannot rot into a hiding place;
- the permission readout is localized end to end, names and states.

The guard drives off `AuraCopy.allKeys`, added for this purpose, rather than a
hand-listed set — a hand-maintained list is precisely what let the earlier gaps
survive, since a key could enter the table and never appear in a test.

The two allowlisted identical pairs are `app.name` ("AURA" is a proper noun) and
`confirmation.riskPrefix` ("risk" is the ordinary Turkish word in this register;
forcing a difference would produce a worse translation).

## Deliberately left in English

- The language picker's own options (`EN`/`TR`, `English`/`Türkçe`) — each must

A sweep of every `Text(`/`Button(`/`Label(`/`GroupBox(`/`LabeledContent(`/
`Section(`/`Toggle(`/`SecureField(`/`TextField(` literal in `Sources/AURA`
returns only those five sites.

## What is still NOT done — the refusal stands on these

1. **The 96 new Turkish strings are unreviewed.** They were written by the
   implementing agent, which cannot judge its own Turkish. The owner is a native
   speaker and has not reviewed them. This session **increased** the size of that
   review from roughly twenty strings to well over a hundred. That is the direct
   cost of the "fix the rest" decision and it is recorded, not softened.
2. **No live VoiceOver verification.** Everything here is `deterministic_harness`.
   A string being present in a table is not proof VoiceOver reads it correctly.
3. **The guard proves the table is complete, not that the UI uses the table.** A
   literal that never became a key is invisible to it. The sweep above is a
   hand-verified snapshot, not an enforced invariant.
4. Under ADR-050 §4 this was authored by the same agent that found the gaps, so it
   requires a different reviewer.

## Net effect

F-005's **coverage** dimension is closed and now guarded against regression. The
`accessibility_localization` sign-off **remains REFUSED**, and the refusal now
rests on (1) unreviewed translation, (2) absent live verification, and (3) reviewer
independence — no longer on missing coverage.

## Falsifiers

Any claim that the Turkish was reviewed, that a live VoiceOver session verified
this, that the guard proves every UI literal routes through the table, that
reviewer independence was satisfied, or that `accessibility_localization` was
obtained, would falsify this record.
